# Foundations · "Ledger"

**Status: foundations named (T-09); palette provisional.** The tokens come from the Claude Design canvas "Altrue core flow" (design direction v0). The names, type scale and spacing scale are the contract for the component cards (T-10 to T-14). The colour values have no brand sign-off, so treat them as provisional until a human approves them. Tokens live as CSS variables in `app/globals.css` and as `ds-*` classes in `tailwind.config.ts`; the two files use the same names.

The idea is Wise's approach, never its brand: the amount is the largest thing on every money screen, plain labelled rows sit between thin rules, there is one strong accent, and every surface is flat.

### Contrast pairs

Use only these pairings for text and control labels. Ratios are WCAG 2.x, computed from the hex values.

| Foreground | Background | Ratio | Use |
|---|---|---|---|
| ink | ground | 16.6:1 | Body text, headings, secondary buttons |
| ink-2 | ground | 5.8:1 | Secondary text, labels |
| accent (green) | ground | 7.0:1 | Accent text and selected outlines |
| on-accent | accent (green) | 7.5:1 | Primary button label |
| demo | ground | 5.4:1 | Demo labels and caveat markers |
| notice-ink | notice-bg | 6.6:1 | Notice body text |

The other accent candidates also clear 4.5:1 with white text (blue 8.7:1, rust 6.7:1, ink 17.9:1) and as accent text on ground (blue 8.1:1, rust 6.2:1, ink 16.6:1), so the Accent menu is safe to try.

**rule is decorative.** At 1.3:1 it fails the 3:1 bar for control edges. Use it for row dividers only. Anything interactive, such as an input or an unselected chip, needs an `ink` or `ink-2` edge.

### Provisional decisions

- **Accent:** green `#2E5E45` stays the default. Blue, rust and ink are still on trial; no one has approved a brand colour.
- **Everything else in the palette** (ground, ink, ink-2, demo, notice) is v0 from the design canvas, not a brand approval.
- Legacy `ink`, `paper`, `moss`, `clay` and `skywash` Tailwind colours still serve the old placeholder pages and are not part of this system. New work uses `ds-*` only.

## Spacing and sizes

A 4 px base. Use the named steps instead of arbitrary values.

| Token | Value | Tailwind | Use |
|---|---|---|---|
| xs | 4 px | `p-ds-xs` | Icon gaps, tight label stacks |
| sm | 8 px | `gap-ds-sm` | Gap between chips, related rows |
| md | 16 px | `p-ds-md` | Default padding and screen gutters |
| lg | 24 px | `gap-ds-lg` | Space between groups |
| xl | 32 px | `mt-ds-xl` | Between sections |
| 2xl | 48 px | `py-ds-2xl` | Page-level breathing room |

Control sizes use the same scale: `touch` 44 px (the floor for anything tappable), `chip` 48 px, `button` 56 px. Use them as `min-h-ds-touch`, `h-ds-chip` and `h-ds-button`.

## Shape

- Pill buttons, 56 px high (`h-ds-button`), full width at the bottom on mobile.
- Chips 48 px high (`h-ds-chip`). Every control is at least 44 px (`min-h-ds-touch`).
- Keyboard focus: 2 px outline in `ds-focus`, offset 2 px (`focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-ds-focus`). Never remove it.
- Notices are flat tinted blocks with rounded corners.

## Never

Shadows, glows, gradients, floating cards, left-border accent cards, stock photos, emoji, and the legacy purple and magenta gradient.

## Copy

Calm and plain, with no guilt or urgency. Say "estimated" and "helped support", never "caused" or "guaranteed". Small amounts are valid. Copy in these stories is placeholder until it passes the two-vendor copy check.
