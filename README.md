# Altrue
Altrue is a meta-charity microdonation app that helps people distribute recurring or one-time donations across high-impact causes. An AI donation assistant guides users through cause discovery, donation splits, and real-world impact estimates like lives protected, children educated, or mosquito nets funded.


# Altrue **Altrue is a meta-charity and microdonation app that helps people turn small recurring donations into thoughtful, evidence-informed impact.** Instead of asking users to choose one charity from an overwhelming landscape, Altrue helps them discover cause areas, compare impact, and distribute their donations across a curated portfolio of high-impact organisations. The first version focuses on simplicity: users can set a monthly giving amount, explore cause areas, receive guidance from an AI donation assistant, and see their projected impact in real-world terms such as lives protected, children educated, mosquito nets funded, treatments delivered, or campaigns supported. ## Product idea Most people want to give, but donation decisions can feel abstract, fragmented, and hard to compare. Altrue makes giving easier by combining three ideas: - **Microdonations:** small monthly or one-time donations that feel financially manageable. - **Meta-charity thinking:** helping users support effective charities, charity evaluators, cause funds, and high-impact interventions. - **Guided decision-making:** a chatbot that helps users understand their values and distribute donations across cause areas. Altrue is not just a payment interface. It is a lightweight decision-support tool for better giving. ## Core concept A user should be able to: 1. Choose a monthly donation amount. 2. Explore cause areas such as global health, climate, animal welfare, education, poverty reduction, and emergency response. 3. Talk to a chatbot about what they care about. 4. Receive a suggested donation split across cause areas or recommended funds. 5. Adjust the split manually. 6. See clear impact estimates. 7. Donate once or set up a recurring subscription. 8. Track cumulative impact over time. ## Key features for version 1 ### Donation setup Users can create either: - A monthly microdonation subscription. - A one-time donation. - A suggested donation split generated by the chatbot. - A manual donation split across multiple cause areas. ### Cause area explorer Each cause area should include: - A plain-language explanation. - Example interventions. - Recommended charities, funds, or evaluators. - Real-world impact statistics. - A confidence level or evidence note. - A suggested donation allocation range. ### AI donation assistant The chatbot helps users answer questions such as: - “What causes should I donate to?” - “How should I split €20 per month?” - “I care about climate and poverty. What would make sense?” - “What is the most effective use of a small donation?” - “Can you explain the impact in simple terms?” The assistant should be warm, clear, and non-judgmental. It should never pressure the user. It should explain trade-offs and let the user make the final choice. ### Impact display Altrue should translate donations into understandable outcomes. Examples: - Mosquito nets funded. - Malaria cases prevented. - Vitamin treatments delivered. - Children supported in school. - Meals or cash transfers funded. - Tonnes of CO₂ avoided or removed. - High-impact advocacy campaigns supported. Impact numbers should always include context and uncertainty. The app should avoid false precision. ## Design principles Altrue should feel: - Calm. - Trustworthy. - Human. - Optimistic but not naive. - Clear enough for a first-time donor. - Useful for people already familiar with effective giving. Avoid guilt-driven copy. Avoid charity clichés. Avoid dark patterns. The product should make giving feel considered, not transactional. ## Suggested first user flow 1. Landing page explains Altrue in one sentence. 2. User selects a donation amount. 3. User chooses “Help me decide” or “I know what I care about.” 4. Chatbot asks 2–4 lightweight questions. 5. App generates a recommended split. 6. User reviews causes and impact estimates. 7. User adjusts allocation if desired. 8. User confirms donation. 9. User sees a dashboard showing monthly and cumulative impact. ## Technical direction A simple first version could be built with: - Frontend: React, Next.js, or Flask templates. - Backend: Flask, FastAPI, or Next.js API routes. - Database: SQLite for MVP, later PostgreSQL. - Payments: Stripe subscriptions and one-time payments. - AI: OpenAI API for chatbot guidance and donation reasoning. - Data: Curated JSON or database tables for cause areas, charities, impact estimates, and evidence notes. ## MVP data model Useful initial entities: - User - DonationPlan - DonationAllocation - CauseArea - Charity - ImpactMetric - ChatSession - ChatMessage - Recommendation ## Example cause areas - Global health and development. - Malaria prevention. - Direct cash transfers. - Education access. - Climate change mitigation. - Animal welfare. - Mental health. - Emergency relief. - Meta-charity and charity evaluation. - Long-term future and catastrophic risk reduction. ## Repository purpose This repository contains the first working version of Altrue: a user-friendly donation guidance app that helps people understand, personalise, and act on their charitable giving. The initial goal is not to solve every donation problem. It is to make the first thoughtful donation easier.
