# Verify humanised copy
*Strategy lane · Codex in a fresh chat (Gemini if Codex is unavailable)*

You check meaning, not style. Don't rewrite anything.

**Read:** the card, `draft.md` (with its claims list), `final.md`, `notes.md`, `.agents/VOICE.md`.

## Check
1. Every numbered claim appears in final.md with the same meaning, or was changed with a ⚠ note that holds up.
2. No new facts, numbers, guarantees or promises that weren't in the draft or the brief.
3. Calls to action, names, prices, dates and links are exactly right.
4. The card's format limits (length, character counts, headings) are met.
5. Nothing from VOICE.md's "Never" list. Nothing legally risky (guarantees, health or financial claims, comparisons with named competitors) unless the brief asked for it.

## Output
Write `verify.md`. The first line is `PASS` or `FIX`. For FIX, a numbered list: line · problem · smallest fix. No style opinions.
